# Ghost Word Game

A console-based Java word game where players take turns adding letters to build a word.

## Features
- Turn-based word gameplay
- Dictionary validation using over 279,000 words
- Word prefix checking
- Word challenges
- Input validation and game-rule enforcement

## Technologies
- Java
- File I/O
- String Manipulation
- Arrays and Conditional Logic

## How to Play
1. Players take turns adding one letter to the current word fragment.
2. A player loses if they complete a valid word containing four or more letters.
3. Players can challenge a word fragment if they believe it cannot form a valid word.
4. The game checks the dictionary to determine the result.

## Requirements
- Java Development Kit (JDK)
- Dictionary text file (`words.txt`)
